# Mod Settings 0.4.0

## New
- Works in the Claude mobile app. Switches are On/Off buttons and drop-down settings are a row of buttons, one per choice. Text and number settings are shown read-only there, because the phone has no text box yet; change them in the desktop app or in /config.

# Mod Settings 0.3.0

## Fixed
- Mod Settings showed no settings. It now reads each installed mod's settings from the mod itself, with the values you saved, and lists them in the mod's own order.
- A change is saved to your settings.json, keeping everything else there. Run /reload-plugins (or restart) for the mod to use it.
