# Claude Photos

Claude Photos is a Claude Code skill plugin for making photos and videos with Higgsfield. Give it a short idea and it writes a model-ready prompt, quotes the credit cost, waits for your yes, then saves the results to a folder.

## Skills

- **photos-prompt-writer**: turns a short idea into one detailed prompt for an AI image or video model.
- **photos-generate**: runs a prompt in Higgsfield, quotes the cost first, generates after your yes, and saves every result without overwriting.

## Install

```
/plugin install higgsfield-photos --marketplace doolecg/higgsfield-photos
```

Requires the Higgsfield MCP server to be connected.
