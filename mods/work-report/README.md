# Work Report

A Claude Code mod that shows what Claude has done for you: tasks finished, estimated hours saved and what that time is worth. Four tabs: Today, Week, Month, Year. Works in the terminal and the desktop app.

## Install

```
/plugin install work-report --marketplace doolecg/work-report
```

## Use

- `/report` opens the pane. A small "Work report" button also sits above the prompt.
- `/report settings` lists the estimates. `/report settings rate 75` and `/report settings emails 15` change them (also documents, images, research, other).

Hours and dollars are estimates. Only prompts you typed that finish with an answer count. Data stays in the mod's own store on your machine.
