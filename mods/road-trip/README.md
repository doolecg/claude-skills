# Road Trip

A small driving game in a pane above the prompt, for the terminal. While Claude works, a bonus coin rolls onto the road each time it finishes a step. When Claude finishes the job, the game pauses on an Arrived card.

## Install

```
/plugin install road-trip --marketplace doolecg/road-trip
```

Type `y` to add the marketplace, then pick the user scope.

## Use

- `/roadtrip` opens the game. It never opens by itself.
- `/roadtrip off` hides it and stops the game clock. `/roadtrip on` brings it back.
- `/roadtrip retro on|off` switches to the 1980s arcade look.
- A / D change lanes, P pauses, G opens the garage, B buys or picks a car.

Avoid barriers, cones and potholes. Collect coins and orange task coins. Quiz gates give coins and nitro for the right lane. Progress (bank, cars, level, best run) is saved between sessions.
