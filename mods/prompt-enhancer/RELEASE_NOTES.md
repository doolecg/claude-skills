# Prompt Enhancer 0.6.0

## New
- An Enabled setting, first in its list, turns the mod off without uninstalling it. Find it in Mod Settings (`/doole_settings`) in the desktop app or `/config` in the terminal.
- The model is now a drop-down (Haiku, Sonnet, Opus or the session's model).
- Settings for the most skills offered and how many recent messages it reads.
