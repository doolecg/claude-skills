# Main Menu 1.7.0

## New
- The Sidebar is now the Main Menu: one menu with a tab for each installed mod. Open it with `/doole_main-menu` (`/sidebar` and `/doole_sidebar` still work, and your settings carry over).
- Mod Settings is a tab of its own, always the last one.
- A mod that is switched off keeps its tab, dimmed, after the others. Opening it shows a Turn on button.

## Changed
- The header reads MAIN MENU, and a thin line sets the Settings tab apart.
